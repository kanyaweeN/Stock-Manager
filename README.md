# 📦 Stock Manager (จัดการสต็อกสินค้า)

เว็บแอปจัดการสต็อกสินค้าส่วนตัว สร้างด้วย Next.js + TypeScript ข้อมูลเก็บไว้ในเบราว์เซอร์ของคุณเอง (ไม่มีเซิร์ฟเวอร์/ฐานข้อมูลกลาง) พร้อมนำเข้ารายการจาก Shopee/Lazada/Watsons/Konvy, วิเคราะห์ส่วนผสม, เตือนวันหมดอายุ, คำนวณต้นทุนสูตรผลิตและราคาที่ควรขาย, วางแผนซื้อของ, สรุปยอดที่จ่ายจริง และซิงก์ข้ามเครื่องผ่าน Google Drive ได้

## ฟีเจอร์

- **จัดการสินค้า** — เพิ่ม/แก้ไข/ลบ, ปรับจำนวนแบบ +/−, ตั้งค่าขั้นต่ำแจ้งเตือน "ใกล้หมด"
- **แสดงผลแบบการ์ด (grid)** พร้อมรูปภาพสินค้า — จอเล็กสลับเป็นแถวลิสต์อัตโนมัติ
- **ค้นหา / กรอง / เรียง** — ค้นหาชื่อและส่วนผสม, กรองหมวดหมู่หลายหมวดพร้อมกัน, ชิปนับจำนวนที่กดกรองได้ (ทั้งหมด / มีสินค้า / ใกล้หมด / หมดแล้ว / ⭐ ของโปรด / 🔁 ซื้อบ่อย / ⏰ ใกล้หมดอายุ / 👥 กลุ่ม / ไม่มีหมวดหมู่), กดป้ายชื่อร้านบนการ์ดเพื่อดูเฉพาะของจากร้านนั้น เรียงเริ่มต้นเป็น **ซื้อล่าสุด** (ของที่เพิ่งซื้อซ้ำจะเด้งขึ้นบนสุด ไม่จมอยู่ล่างเหมือนตอนเรียงตามวันที่เพิ่ม)
- **หมวดหมู่หลายชั้น** — สินค้า 1 ชิ้นอยู่ได้หลายหมวด, รองรับหมวดย่อยแบบ `หมวดแม่ > หมวดลูก` (กรองด้วยหมวดแม่แล้วเห็นของในหมวดย่อยครบ), ลากวางเพื่อย้ายหมวด
- **จัดกลุ่มสินค้า** — ของชิ้นเดียวกันที่ซื้อคนละร้าน จับรวมเป็นกลุ่มได้โดยไม่ต้องลบทิ้ง
- **สถานะสินค้า** — ซื้อซ้ำได้ / ไม่ควรซื้อ / ได้ของอยู่แล้ว
- **ของโปรด & ซื้อบ่อย** — ⭐ ปักดาวเองได้ ส่วน 🔁 "ซื้อบ่อย" ระบบนับให้เองจากประวัติราคา (ซื้อครบ 3 ครั้งขึ้นไป) ไม่ต้องติ๊กเอง
- **วันหมดอายุ** — กรอกวันบนฉลาก หรือกรอกวันที่เปิดใช้ + PAO (สัญลักษณ์กระปุกเปิดฝา เช่น `12M`) ก็ได้ ระบบเลือก **วันที่มาถึงก่อน** ให้อัตโนมัติ พร้อมป้ายเตือนบนการ์ด — ของที่ไม่ได้กรอกอะไรเลยจะไม่ถูกนับว่า "ยังไม่หมดอายุ"
- **ทำนายว่าจะใช้หมดเมื่อไร** — จดอัตราการใช้ให้อัตโนมัติทุกครั้งที่กด +/− บนการ์ด แล้วประเมินว่าเหลืออีกกี่วัน (ถ้าข้อมูลยังน้อยเกินไปจะบอกว่าไม่รู้ ไม่เดาให้)
- **ขนาดบรรจุ & ราคาต่อชิ้น** — ของที่ขายยกแพ็คกรอกจำนวนต่อแพ็คได้ การ์ดจะโชว์ราคาต่อชิ้นย่อยและจำนวนรวมทั้งหมดให้
- **ถังขยะ** — ของที่ลบไปกู้คืนได้ (เก็บ 100 รายการล่าสุด) อยู่ในหน้าตั้งค่า → แท็บ **สำรอง/กู้คืน**
- **นำเข้าออเดอร์จากร้านออนไลน์** — รองรับ **Shopee / Lazada / Watsons / Konvy** เลือกร้านแล้ววางโค้ด HTML จากหน้าออเดอร์ (Ctrl+U) ระบบแยกชื่อ/จำนวน/ราคา/ขนาด/ร้านค้า/วันที่สั่งซื้อ/ค่าส่ง/ส่วนลด ให้อัตโนมัติ พร้อมเทียบยอดกับที่หน้าออเดอร์บอกว่าตรงไหม ตรวจสอบและแก้ก่อนนำเข้าได้ เจอของที่มีอยู่แล้วจะเสนอ **รวมเข้ารายการเดิม** (เลือกได้ว่าจะอัปเดตฟิลด์ไหนบ้าง) แทนการสร้างรายการซ้ำ
- **วิเคราะห์ส่วนผสม (INCI)** — แกะลิสต์ส่วนผสมจากฉลาก ติดแท็ก (เช่น กันแดด, กรด, น้ำหอม), เตือนคู่ส่วนผสมที่ไม่ควรใช้ร่วมกัน, ตั้งลิสต์ "ส่วนผสมที่แพ้" และโปรไฟล์สภาพผิวเพื่อให้คะแนนความเข้ากัน — ทำงานออฟไลน์ล้วน ไม่เรียก API ภายนอก
- **คำนวณต้นทุน** — สร้างสูตรผลิต ดึงราคา/ขนาดจากสินค้าในสต็อกมาคิดต้นทุนต่อชิ้น รวมค่าแรง/ค่าใช้จ่ายอื่น และคำนวณกำไรจากราคาขาย (ไม่ตัดสต็อกอัตโนมัติ) — ค่าที่ดึงมาเป็น **สแนปช็อต ณ วันที่เลือก** ถ้าราคา/ขนาดแพ็คในสต็อกเปลี่ยนไปแล้วจะขึ้นเตือนพร้อมปุ่มดึงค่าล่าสุดมาทับ และเตือนเมื่อใส่วัตถุดิบชิ้นเดิมซ้ำในสูตรเดียว (เตือนเฉยๆ ไม่กัน เพราะใช้ของชิ้นเดียวกันสองขั้นตอนก็มีจริง)
- **คิดราคาขาย** — บอกว่า "ควรขายเท่าไร" จากต้นทุนต่อชิ้น + กำไรที่อยากได้ + ค่าธรรมเนียมร้าน/แพลตฟอร์ม + ค่ากล่อง/ค่าส่ง พร้อมปัดราคาให้สวย (ลงท้าย 9 / เต็มบาท / ทีละ 5 / ทีละ 10) มีตารางเทียบว่าอยากได้กำไรกี่ % ต้องตั้งราคาเท่าไร เข้ากระเป๋าจริงเท่าไร กดเลือกราคาไปใส่ในสูตรได้เลย และเตือนเมื่อราคาที่ตั้งไว้ยังไม่ถึงเป้าหรือขาดทุน
- **วางแผนซื้อของ** — จดว่าเดือนหน้า/ปีใหม่ต้องซื้ออะไร ตั้งงบได้ ระบบรวมยอดให้ว่าต้องใช้เงินเท่าไร ซื้อไปแล้วเท่าไร เหลืออีกเท่าไร ติ๊กเช็กลิสต์ทีละชิ้น และเสนอของที่หมด/ใกล้หมด/ติดธง "ซื้อซ้ำได้" มาให้เลือกใส่แผน (ไม่ยุ่งกับจำนวนในสต็อก)
- **ประวัติราคา** — เก็บราคาและร้านทุกครั้งที่ซื้อ ดูราคาเฉลี่ย/ต่ำสุด/สูงสุด และรู้ทันทีว่าครั้งล่าสุดของขึ้นราคาหรือเปล่า (นำเข้าออเดอร์ซ้ำต่อประวัติให้อัตโนมัติ)
- **ค่าส่ง/ส่วนลดระดับออเดอร์** — เก็บแยกจากราคาสินค้า ออเดอร์เดียวที่มีของหลายชิ้นจึงไม่ถูกนับค่าส่งซ้ำตามจำนวนชิ้น แก้/ลบย้อนหลังได้ในหน้าสรุปยอด และเตือนเมื่อกำลังนำเข้าหน้าออเดอร์เดิมซ้ำ
- **สรุปยอด** — ยอดที่จ่ายจริงคิดจากประวัติราคาทุกครั้งที่ซื้อ ไม่ใช่ของที่เหลือในสต็อก จึงดูย้อนหลังได้แม้ของจะใช้หมดไปแล้ว: จ่ายเดือนนี้เทียบเดือนที่แล้ว, เฉลี่ยต่อเดือน, ยอดทั้งปี, แยกตามหมวด/รายเดือน/รายชิ้น/ร้านที่ซื้อ พร้อมบอกว่าของชิ้นไหนราคาต่างกันมากที่สุดระหว่างร้าน และประโยคสรุปว่าอะไรกินงบ อะไรราคาขึ้น และข้อมูลตรงไหนยังขาด
- **จัดหมวดหมู่ทีละหลายชิ้น** — เลือกหลายชิ้นแล้ว **เพิ่ม** / **เอาออก** / **แทนที่ทั้งหมด** ได้ (ไม่ใช่ทับของเดิมทางเดียวเหมือนเดิม) พร้อมแสดงตัวอย่างผลลัพธ์รายชิ้นก่อนกดยืนยัน — สีเขียว = หมวดที่จะเพิ่ม, ขีดฆ่าแดง = หมวดที่จะหายไป
- **เลือกหลายชิ้นพร้อมกัน** — ปุ่ม **เลือกหลายรายการ** อยู่ท้ายแถวตัวกรองที่ตรึงไว้ (ไม่ต้องเข้าเมนู ⋯ แล้ว) เลือกทั้งหมดเท่าที่ตัวกรองแสดงอยู่ แล้วจัดหมวดหมู่/จัดกลุ่ม/ของโปรด/ใส่สูตร/ใส่แผนซื้อ/ลบทีเดียว
- **บันทึกอัตโนมัติลงไฟล์** — ใช้ Origin Private File System (OPFS) ของเบราว์เซอร์เป็นหลัก สำรองด้วย localStorage และเลือกผูกกับไฟล์ `.json` บนเครื่องจริงได้ (Chrome/Edge)
- **ซิงก์ผ่าน Google Drive** (ไม่บังคับ) — เก็บข้อมูลทั้งก้อนเป็นไฟล์เดียวในโฟลเดอร์ซ่อนของแอป ใช้ย้าย/ซิงก์ข้ามเครื่องได้
- **ส่งออก Google Sheets / CSV** และ **สำรอง-กู้คืนเป็นไฟล์ JSON**

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000)

### คำสั่งอื่นๆ

```bash
npm test          # รันเทสต์ (vitest) — ครอบชั้นคำนวณใน lib/
npm run typecheck # ตรวจ type ด้วย tsc
npm run lint      # ตรวจโค้ดด้วย ESLint
npm run build     # build สำหรับ production
npm run start     # รันเวอร์ชัน production ที่ build แล้ว
```

> **พอร์ตต้องเป็น 3000 เสมอ** — ข้อมูลเก็บใน OPFS/localStorage ซึ่งผูกกับ origin เปิดคนละพอร์ตจะเจอฐานข้อมูลเปล่าเหมือนข้อมูลหาย (`npm run dev` พินพอร์ตไว้ให้แล้ว)

## การเก็บข้อมูล

ไม่มีฐานข้อมูลหรือเซิร์ฟเวอร์ ข้อมูลทั้งหมดอยู่ในเบราว์เซอร์ของผู้ใช้:

1. **OPFS** (Origin Private File System) — ไฟล์จริงที่เบราว์เซอร์จัดการให้ ใช้เป็นค่าเริ่มต้น
2. **localStorage** — สำรองคู่กันเสมอ
3. **ไฟล์บนเครื่องจริง (ไม่บังคับ)** — กด "ผูกกับไฟล์บนเครื่อง" ในหน้าตั้งค่าเพื่อเขียนข้อมูลไปยังไฟล์ `.json` ที่เลือกไว้ด้วย (ต้องใช้ Chrome/Edge เพราะพึ่ง File System Access API)

หากต้องการย้ายข้อมูลไปเครื่องอื่น ใช้ **Google Drive** (ด้านล่าง) หรือปุ่ม **สำรองข้อมูล (ดาวน์โหลด)** / **กู้คืนจากไฟล์** ในหน้าตั้งค่า

### เวอร์ชันของโครงสร้างข้อมูล

ข้อมูลมีเลขเวอร์ชัน (`schemaVersion`) กำกับ ทุกครั้งที่โหลดจากเครื่อง / ดึงจาก Drive / กู้คืนจากไฟล์ ระบบจะรัน migration เฉพาะขั้นที่ยังไม่เคยรันให้อัตโนมัติ ข้อมูลเก่าจึงเปิดได้เสมอโดยไม่ต้องแปลงเอง

## เชื่อมต่อ Google (ไม่บังคับ)

ทั้ง Drive และ Sheets ใช้ **OAuth Client ID ตัวเดียวกัน** เชื่อมผ่าน Google Identity Services ฝั่ง client ล้วนๆ ไม่มี backend และไม่มี client secret ฝังอยู่ในโค้ด

**เตรียม OAuth Client ID:**

1. สร้างโปรเจกต์ใน [Google Cloud Console](https://console.cloud.google.com/) แล้วเปิดใช้งาน **Google Drive API** (และ **Google Sheets API** ถ้าจะส่งออกชีตด้วย)
2. ตั้งค่า **OAuth consent screen** (User type: External) แล้วเพิ่มอีเมลของคุณใน Test users
3. สร้าง **OAuth Client ID** ประเภท "Web application" แล้วเพิ่ม URL ของแอป (เช่น `http://localhost:3000`) ใน Authorized JavaScript origins

### Google Drive — ซิงก์ข้ามเครื่อง (แนะนำ)

ใส่ Client ID ในหน้าตั้งค่า → แท็บ **Google Drive** แล้วกดเชื่อมต่อ ระบบจะเก็บข้อมูล **ทั้งก้อน** (สินค้า, หมวดหมู่, สูตรต้นทุน, โปรไฟล์ผิว ฯลฯ) เป็นไฟล์ JSON ไฟล์เดียวใน `appDataFolder` — โฟลเดอร์ซ่อนเฉพาะแอป ไม่ปะปนกับไฟล์อื่นใน Drive และแอปอื่นมองไม่เห็น

- **อัปโหลด** = เอาข้อมูลในเครื่องขึ้นไปทับบน Drive
- **ดึงลง** = เอาข้อมูลบน Drive มาทับในเครื่อง **ทั้งหมด**

### Google Sheets — ส่งออกอย่างเดียว

1. สร้าง Google Sheet เปล่า แล้วคัดลอก Spreadsheet ID จาก URL (ส่วนระหว่าง `/d/` กับ `/edit`)
2. ใส่ Client ID และ Spreadsheet ID ในหน้าตั้งค่า → แท็บ **ส่งออก Sheet**

แท็บนี้**ส่งออกทางเดียว ไม่มีการดึงกลับ** เพราะชีตเก็บได้แค่ตารางสินค้า การดึงกลับจะทำให้สูตรต้นทุนและข้อมูลที่ไม่มีคอลัมน์รองรับหายไป — ถ้าต้องการซิงก์สองทางให้ใช้ Google Drive แทน ส่วนชีตเหมาะกับการเอาไปทำรายงาน/กราฟต่อ

### ตั้งค่าเริ่มต้นด้วย env (ไม่ต้องกรอกเองทุกครั้ง)

Client ID และ Spreadsheet ID ไม่ใช่ความลับ (เปิดเผยได้อยู่แล้วตอนทำ OAuth) จึงตั้งเป็นค่าเริ่มต้นผ่าน environment variable ได้:

```bash
cp .env.local.example .env.local
```

แล้วแก้ค่าในไฟล์ `.env.local`:

```
NEXT_PUBLIC_GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
NEXT_PUBLIC_GOOGLE_SHEET_ID=your-spreadsheet-id
```

`NEXT_PUBLIC_GOOGLE_CLIENT_ID` ใช้ร่วมกันทั้ง Drive และ Sheets รีสตาร์ท `npm run dev` ครั้งเดียว หน้าตั้งค่าจะกรอกค่าให้อัตโนมัติทุกครั้งที่เปิดเบราว์เซอร์ใหม่ (ไม่ต้องพิมพ์เอง) — ถ้าเคยตั้งค่าไว้ในหน้าตั้งค่าด้วยตัวเองมาก่อน ค่านั้นจะยังคงมีสิทธิ์เหนือกว่า `.env.local` เสมอ ไฟล์ `.env.local` ไม่ถูก commit ขึ้น git
